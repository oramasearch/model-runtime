# model-runtime v0.1.1

**Released 2026-11-16. A patch release.** It rewords one comment in the public interface and one
contributor rule. The library's code and behavior are the same as [v0.1.0](v0.1.0.md), which lists
everything the library holds.

## What it includes

| Change | What |
|---|---|
| #8 | The comment on `model::OnToken` (`include/model/engine.hpp`) now names the token callback as an injected dependency, without an internal decision number. The matching naming rule in `CLAUDE.md` is reworded. |
| this release | The version `0.1.1` (`project(VERSION)` in `CMakeLists.txt` and `model::kVersion`), held by the tests, and these notes. The v0.1.0 notes are rewrapped so their release page renders without a stray line break. |

## What it does not include

- No code change: the interface, the stub engine and the MLX backend are those of v0.1.0.
- **No libtorch, llama.cpp or CUDA backend yet.** Their CMake options exist, but each returns the
  stub engine.
- **No server and no image.** Issue #3 tracks serving a model over an OpenAI-compatible HTTP API,
  as an image.
- No pull request was open at the cut, so nothing was deferred.

## Known issues

- None filed. As in v0.1.0, the test that round-trips text through a real tokenizer model runs only
  when `ORAMA_TOKENIZER_MODEL` names a SentencePiece model; without one it passes without checking
  anything, and it did not run for this release.
